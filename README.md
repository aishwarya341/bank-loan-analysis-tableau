# Bank Loan Analysis & Approval Performance Dashboard – Tableau

📊 Project Overview

The Bank Loan Analysis Dashboard is an interactive Tableau dashboard created to analyze loan applications, approval performance, loan status, credit scores, customer demographics, and geographic loan trends.

The dashboard presents loan information through interactive visualizations and helps identify important patterns in loan applications and approval performance.

🎯 Objectives

- Analyze total loan applications
- Measure loan approval performance
- Analyze approved, rejected, and pending loans
- Analyze approved loan amounts
- Understand credit score distribution
- Analyze loan applications by age group
- Compare approved loan amounts across cities
- Analyze loan applications by gender
- Understand geographic loan trends
- Present loan information through an interactive dashboard

💡 Key Insights

The dashboard helps identify loan approval patterns, the distribution of approved, rejected, and pending applications, credit score trends, age-wise application patterns, and city-wise approved loan amounts.

The analysis includes:

- 50,000 total loan applications
- 20,854 approved loans
- 20,838 rejected loans
- 8,308 pending loans
- 41.71% approval rate
- Average credit score of approximately 600
- Approximately ₹53B in approved loan amount

📊 Dashboard KPIs

- Total Applications – 50,000

- Approval Rate – 41.71%
- Avg Credit Score – 600
- Approved Loans – 20,854
- Rejected Loans – 20,838
